# РУКОВОДСТВО ПОЛЬЗОВАТЕЛЯ И ТЕХНИЧЕСКАЯ СПЕЦИФИКАЦИЯ
## Утилита сборки и распаковки анимаций загрузки MIB2STD (Boot Tool)

### 1. ОБЩЕЕ ОПИСАНИЕ
Данный скрипт представляет собой специализированный инженерный инструмент для декомпиляции (распаковки) и компиляции (упаковки) файлов анимации загрузки формата `.boot` (например, `startup.boot`), используемых в автомобильных головных устройствах платформы **MIB2 Std** (Discover Media, Composition Media производства TechniSat/Preh, устанавливаемых на автомобили концерна VAG: VW, Skoda, Seat).

Скрипт полностью обрабатывает специфический двухканальный формат представления графики **MIB2 GRAYA**, основанный на алгоритме кастомной субдискретизации хроматического сдвига (Chroma Subsampling), а также транслирует бинарные опкоды логики анимации в человекочитаемый текстовый файл сценария (`script.txt`) и обратно.

---

### 2. РЕЖИМЫ РАБОТЫ И ПАРАМЕТРЫ ЗАПУСКА

Запуск скрипта осуществляется через интерфейс командной строки (CLI). Скрипт поддерживает два основных взаимоисключающих режима работы: `unpack` (распаковка) и `pack` (упаковка).

#### А. Режим распаковки (unpack)
Используется для декомпиляции готового файла `.boot` на исходные кадры формата `.png` и текстовый файл описания логики воспроизведения.

**Синтаксис запуска:**
```bash
python mib2_boot_tool.py unpack <путь_к_файлу.boot> [<путь_к_папке_вывода>]
```

**Доступные параметры:**
*   `file` *(обязательный позиционный параметр)*: Относительный или абсолютный путь к бинарному файлу контейнера анимации (например, `startup.boot`).
*   `outdir` *(опциональный позиционный параметр)*: Путь к директории, в которую будут сохранены извлеченные ресурсы. Если этот параметр не указан, утилита автоматически создаст папку с именем исходного файла (без расширения) в текущем рабочем каталоге.

#### Б. Режим упаковки (pack)
Используется для сборки отредактированных или созданных с нуля ресурсов (кадров `.png` и файла сценария `script.txt`) в валидный бинарный контейнер `.boot`, готовый к прошивке или установке в головное устройство.

**Синтаксис запуска:**
```bash
python mib2_boot_tool.py pack <путь_к_папке_с_ресурсами> <имя_выходного_файла.boot> [--bits <значение>]
```

**Доступные параметры:**
*   `folder` *(обязательный позиционный параметр)*: Путь к исходной директории, внутри которой обязательно должны находиться файл сценария `script.txt` и все задействованные в нем графические ассеты в формате `.png`.
*   `output` *(обязательный позиционный параметр)*: Имя или полный путь создаваемого бинарного файла контейнера (например, `custom_startup.boot`).
*   `--bits` *(опциональный именованный параметр)*: Диапазон значений от `1` до `8`. Задает принудительное снижение глубины цвета (постеризацию) каждого цветового канала перед процедурой упаковки. Данный параметр критически важен для агрессивного сжатия тяжелых анимаций с целью удержания итогового объема файла в жестких рамках оперативной памяти загрузчика (рекомендуется `--bits 4` при превышении лимита в 1 Мб).

### 3. ПРИЛОЖЕНИЕ А: СПЕЦИФИКАЦИЯ СЦЕНАРИЯ АНИМАЦИИ (script.txt)

Текстовый файл сценария определяет логику работы графического движка магнитолы в покадровом режиме. Каждый значащий оператор пишется с новой строки. Символ `#` используется для обозначения комментариев (весь текст после `#` до конца строки полностью игнорируется компилятором). 

Каждая строка при компиляции превращается в 32-байтовую бинарную структуру, содержащую внутренний идентификатор команды и до 6 управляющих аргументов. При распаковке в конце строки автоматически генерируется маркер `# ID=<число>`, указывающий на исходный индекс команды в бинарном дереве. При ручном создании скрипта эти маркеры указывать не обязательно.

#### Сводная таблица команд графического движка MIB2

| Название команды | Назначение | Пример использования |
| :--- | :--- | :--- |
| `begin()` | Инициализация и запуск контекста сцены выполнения. Всегда стоит первой. | `begin()` |
| `end()` | Завершение сценария анимации и передача контроля загрузчику ОС. | `end()` |
| `clear_screen()` | Полная очистка текущего фреймбуфера (заливка экрана черным цветом). | `clear_screen()` |
| `set_resolution(W, H)` | Задание базового разрешения экрана вывода. Обычно: 800х480. | `set_resolution(800, 480)` |
| `draw_bg(img_name, x, y)` | Отрисовка базового полноэкранного фонового изображения. | `draw_bg(img_00, x=0, y=0)` |
| `draw_sticker(...)` | Отрисовка спрайта/слоя с индивидуальными параметрами прозрачности и Z-слоя. | `draw_sticker(img_01, x=240, y=100, blend_mode=19, z_index=1, frame_buffer=0)` |
| `wait(секунды)` | Приостановка выполнения сценария на заданное время (шаг — 0.01 сек). | `wait(0.15)` |
| `start_animation()` | Запуск циклического аппаратного воспроизведения накопленных кадров. | `start_animation()` |
| `if STICKER == ID:` | Условный оператор для ветвления логики отображения в зависимости от конфигурации. | `if STICKER == 0:` |
| `else:` | Ветвь условия, если условие оператора `if` вернуло ложь. | `else:` |
| `endif` | Обязательное закрытие блока условного оператора `if/else`. | `endif` |
| `set animation id=ID` | Служебная команда, задает ID анимации для привязки к скину меню. | `set animation id=101` |

### 4. ПОДРОБНОЕ ОПИСАНИЕ АТРИБУТОВ КОМАНД

#### set_resolution(width, height)
*   **width**: Ширина экрана вывода в пикселях. Для дисплеев MIB2 Std стандартное значение `800`.
*   **height**: Высота экрана вывода в пикселях. Стандартное значение `480`.

#### draw_bg(image_name, x, y)
*   **image_name**: Имя файла изображения без расширения (например, `img_00`). Компилятор ищет файл `img_00.png` в рабочей папке. Название должно быть буквенно-цифровым.
*   **x**: Смещение по координате X (горизонталь) для левого верхнего угла фона. По заводу всегда `0`.
*   **y**: Смещение по координате Y (вертикаль) для левого верхнего угла фона. По заводу всегда `0`.

#### draw_sticker(image_name, x, y, blend_mode, z_index, frame_buffer)
*   **image_name**: Имя накладываемого спрайта/кадра (например, `img_01`).
*   **x** / **y**: Точные координаты привязки левого верхнего угла изображения на экране. Позволяет центровать логотипы меньшего разрешения на фоне (например, `x=250, y=140`).
*   **blend_mode**: Режим наложения прозрачности альфа-канала.
    *   `1`: Стандартное непрозрачное наложение (Alpha игнорируется).
    *   `19`: Режим **Premultiplied Alpha** (наиболее частый). Сигнализирует графическому сопроцессору, что цвета пикселей в PNG уже предварительно умножены на значения прозрачности альфа-канала. Обеспечивает плавное слияние границ логотипов без эффекта черного/белого ореола и без тормозов отрисовки.
*   **z_index**: Порядок отрисовки слоев (высота стека). Кадры с `z_index=1` рисуются поверх фона `draw_bg` (у которого индекс по умолчанию `0` или ниже).
*   **frame_buffer**: Индекс аппаратного кадрового буфера устройства, в который производится рендеринг. Стандартное значение `0` (или `4294967295` для автоматического назначения).

#### wait(time_period)
*   **time_period**: Время задержки в секундах, выраженное числом с плавающей точкой (например, `0.04`, `0.1`, `1.50`). Внутренний таймер работает с точностью до сотых долей секунды (мультипликатор `* 100` переводит значение в системные тики). Используется для регулировки частоты кадров (FPS) анимации.

#### if STICKER == condition_id:
*   **condition_id**: Числовой идентификатор модификации или выбранной конфигурации оформления 
В заводских скриптах проверяется условие **STICKER == 0** (базовая комплектация). Другие варианты **condition_id** не проверялись.
